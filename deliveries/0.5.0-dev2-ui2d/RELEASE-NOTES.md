## 下载与使用

已有完整0.4.0-dev1基础包：下载 `companion-update-0.5.0-dev2-ui2d.zip`（约6.7MiB）和 `character-2d.companion.json`（约9.9MiB）。

1. 从托盘退出软件，完整解压小更新包。
2. 把旧软件的 `companion-desktop.exe` 拖到 `apply-ui-update.cmd` 上。
3. 更新成功后启动软件，在角色工作室选择“PNG角色包”。
4. 选择 `character-2d.companion.json`，检查预览，再确认启用。

原模型沿用。角色、聊天和密钥保留；可用 `rollback-ui-update.cmd` 回退。更新中断时重跑同一更新器，不要删除事务或备份。

首次使用需先下载并完整解压[原Windows基础包](https://github.com/HarryShenwunai/AI-radio-stream-help/releases/tag/v0.4.0-dev1-candidate)。小更新不是独立的Electron/模型安装包。

本地面部方向估计为可选组件：下载 `tracking-addon-cp312-win-x64-v3.zip`（约79.6MiB），放在小更新解压目录，退出软件后运行 `install-tracking-addon.cmd`。安装不自动开启摄像头；可恢复禁用。普通文字与语音不依赖此组件。
