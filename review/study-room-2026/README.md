# 学习场景与双眼细节修订

原界面围绕聊天展开，学习缺少目标、专注和复盘流程；闭眼局部线条偏硬。本轮沿用原角色、手杯固定，把角色和工作台分区，加入真实可操作的学习状态机。设计参考及产品边界见 `docs/design/study-room-2026.md`。

## 可复核证据

- `render-region-report.json`：27 张实际 Core 渲染帧，指定眼部区域之外改变像素为 0。正常睁眼仍有眼部范围内 2 个像素的 1 级差异，不声称整图逐像素不变。
- `lid-contract.json`：左右眼睑 alpha 逐像素一致；透明区域 RGB 不变；虹膜、眼白、刘海遮挡文件逐字节不变。全脸生成候选未直接替换，提取了眼睑局部 RGB 差值。
- `core-verification.json`：46 姿态、21 眨眼帧、双虹膜遮罩、手杯与袖子固定，以及真实 Core 的动作采样。
- `session-tests.txt`：状态机测试与 21,615 次有界状态转换探索（8 层），检查暂停、恢复、重复保存、休息、存储恢复等不变量。这不是无界证明。
- `browser-report.json`：实际 HTTP 应用、Core/WebGL、学习流程、静音、草稿不发送、角色隔离、日夜与多尺寸布局。新增加主操作和对话底栏不裁切、夜间场景边界断言。
- `quality.json` / `quality-logs/`：冻结源码后执行的完整质量检查，包含源码哈希。
- `artifacts.json`：实际截图、正常流程 MP4、双眼近景 MP4、模型包和证据包的哈希；图像和私有模型单独交付，不上传仓库。

`imagegen-prompt.json` 保留内置 image_gen 的完整提示词与局部应用说明。原始图不覆盖。

## 明确限制

本轮“0”只适用于上述已量测约束，不等于与标准原图完全一致，也不代表用户已认可眼部观感。AI 拆解/复盘调用现有连接能力；未连接时显示连接入口，不生成虚假建议。学习模板是本地模板，未冒充 AI 结果。无假在线人数或默认开启直播。

Windows 10/11、RTX 4060、官方 Cubism Editor 复开、Live2DViewerEX 实际导入、真实微信/Bilibili 联动仍未验收；GitHub Actions 的既有账号阻塞未解除。草稿 PR 不等于部署或主分支已更新。
