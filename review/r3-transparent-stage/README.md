# R3 透明舞台与实际运行证据

本候选隐藏原矩形底层，清理头发和蒸汽边缘。头发 RGB 与原图逐像素相同；脸部交界的原透明度受到保护。20 个其他原图层保持字节一致，手杯固定，保留双眼绑定。

## 证据与自动约束

- `source-contract.json`：实际素材尺寸、RGB、透明度及原图层保护。
- `face-overlap-regression.json`：实际素材通过；注入透明缺口后检查拒绝。
- `core-verification.json`：实际 Core 加载，46 姿态、21 眨眼帧、左右虹膜独立遮罩，手杯袖子几何固定，12.5 秒动作样本。
- `quality.json` / `quality-logs/`：805 Python、9 桌面 Python、135 前端 Node、27 桌面 Node 测试通过，无跳过；Lint、10 模块严格类型、架构规则和 19 个负面测试通过。负面夹具日志中的预期 FAIL 用来证明质量门禁会拒绝错误，不代表总测试失败。
- `browser-report.json`：真实应用导入、错误注入/恢复、双眼闭合、手机画布尺寸与新帧、角色切换释放画布。使用隔离 HTTP 服务和测试 AI，不连接真实账号。
- `artifact-manifest.json` / `package-check.json`：交付截图、MP4、三种模型包的 SHA256 和实际导入格式检查。

逐图审查发现并修复刘海交界缺口。另修复检查本身将 16 位灰度饱和为不透明区域的问题，新增位深拒绝测试。手机截图原本早于 ResizeObserver/绘制完成，现等待实际画布匹配和新帧；不以固定等待或仅无页面溢出代替检查。

本轮未改变已有形式化验证覆盖的后端状态机，因此未重复声称新增形式化证明。新增约束落在自动测试和实际像素/几何检查中。

## 限制

这是可播放、待用户视觉审查的候选；小幅头动与视线，非完整大转头。闭眼轮廓与光影仍需按实际审美审查。未验收用户 Windows 10/11、RTX 4060、官方 Cubism Editor 复开、Live2DViewerEX 实际导入、微信或 Bilibili 联动。GitHub Actions 存在平台账号阻塞，本地通过不等于远端 CI 通过。截图、视频与原始素材通过用户私人文件交付，不把角色素材或第三方 Core 上传仓库。
