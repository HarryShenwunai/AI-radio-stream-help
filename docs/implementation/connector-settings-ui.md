# 平台设置组件

2026-11-12。本模块是本机控制面板，不负责登录平台或发送网络消息。

`app/static/connectors-ui.js` 在 `app.js` 后加载，动态加入“平台”导航和视图。复用 `api`、`currentCharacterId`、`showView`、`toast`。API POST 明确传入当前身份，响应再次核对身份和请求序列。`adoptState` 在身份切换时调用 `window.CompanionConnectorsUI.resetCharacter()`，立即清空待审核内容、配对令牌和凭据草稿。

微信只接 AstrBot 私聊绑定。默认先预览，启用自动回复有明确确认。逐条批准会交给桥接服务，界面不把批准、适配器交接当成送达。语音明确是音频文件。暂停操作调用 `wechat/stop`，后端须先关闭自动批准并取消待发，保留配对和收件预览；绑定当前角色可以在关闭开关后重新配置。

配对令牌仅 configure 返回一次。组件放入只读密码框，显式点击才显示或复制，不写入浏览器存储。离开视图、页面隐藏、原生窗口暂停或身份切换会清空。复制是用户触发的系统剪贴板动作，组件不会擅自读取或改写其后内容。

哔哩哔哩连接按钮需确认，才提交官方 Open Live 应用凭据、直播间和主播身份码。密钥和身份码不从状态恢复，提交后清空。公开角色设定独立填写。弹幕只可“生成预览”，无发送弹幕/公开播出按钮。错误和外来弹幕用 textContent，不拼接 HTML。

组件只在本页可见且窗口未隐藏时每五秒读取一次状态，不在挂载时联网，不自动建立平台连接。前端最多渲染 30 条微信预览、20 条弹幕和 20 条回复。状态轮询会替换列表，避免保留旧卡片和闭包引用。

已运行 `node tests/test_connector_settings_ui.mjs`，10 项通过。它使用E1 最小 DOM 和 fake API，覆盖权限确认、身份切换、令牌清理、隐藏时停止轮询及本机预览标签；证据见 `review/connector-settings-ui-check.json`。这不是平台登录、真实发送、完整浏览器或送达验收。完整 Chrome 集成由独立前端/QA 检查。
