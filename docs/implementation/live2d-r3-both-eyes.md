# R3 双眼修订候选

保留 R3 原稿、刘海与手杯固定姿势；两眼各自建立眼白、完整虹膜、闭眼补画与原稿前景遮挡。闭眼纹理使用完整补画压缩展开，补足明暗并柔化过渡。可见虹膜采用原稿像素，补画用于外缘与隐藏区域；不宣称已经完成大幅转头时的完整眼眶透视。

左眼 ParamEyeLOpen 与右眼 ParamEyeROpen 可独立控制；Idle 使用 --bound-both-eyes 同步眨眼，旧模型默认不开启此轨道。视线范围左眼 ±3.5/1.8、右眼 ±3.2/1.6 原画像素，原版为 ±1.1/0.55。前景刘海保持遮挡。

原生工程及输出保存在 .build/r3-both-eyes/character-both-eyes.psd2live、runtime/original.cmo3 和 runtime/model.model3.json。补画提示词与源图保存在同目录 imagegen-prompts.json；制作脚本保存在 scripts/r3_both_eyes，依赖已有 R3 源素材、PSD2Live 3.6.7 和本地获许可的 Core，不能独立分发第三方工具。

验证：实际 Cubism Core 检查 46 个姿态、21 张闭合/睁开帧，双虹膜遮罩各 1，手杯及袖子网格不动，呼吸仅改变 Torso；眨眼起止像素相同。动作生成测试 2 项、适配器测试 15 项通过。逐帧检查补画、刘海遮挡和视线极限；近看仍受原稿分辨率和刘海遮挡限制。未在用户 Windows 真机验收，未获用户最终视觉认可，未部署或公开。

## 后续细节修订

双眼眼白/虹膜遮罩随对应眼睑开合参数收拢，避免只靠贴图覆盖留下边缘漏光。眨眼、视线和小幅头动采用平滑起停曲线，以 60 Hz 采样输出可兼容的线性片段；保留原来的闭合快、睁开慢节奏。复查 46 个实际 Core 姿态和 21 张眨眼帧，固定手杯检查通过，逐帧审查未见新增明显遮挡错误。当前仍是待用户视觉审查的候选，不代表 Windows 真机验收。
