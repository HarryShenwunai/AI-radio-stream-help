# 本地语音输入与运行设置

2026-11-12。默认本机识别，麦克风按钮明确开始/结束，最长60秒；没有常开录音或自动发送聊天。

`app/static/voice-input.js` 使用真实浏览器 MediaRecorder 收集录音，Web Audio 解码，OfflineAudioContext 降混/重采样为单声道16kHz PCM16 WAV。只向同源 `/api/transcribe` 上传，附角色身份和操作ID。结果检查身份/操作ID后填入当前角色草稿；浏览器转写是用户手动选择的独立选项，保留在线识别提示。不提供缺模型时的在线自动降级。

开始前检查 `/api/voice/status`，组件/模型缺失时不请求麦克风；不在聊天时触发模型下载。停止/隐藏/退出/换角色会停止所有麦克风 tracks、取消请求并尽力发送操作取消。权限等待结束后的迟到 stream 也会立即停止。浏览器底层解码/重采样无法强制抢占，过期结果会丢弃，不再上传。根进程的 ASR 取消和模型计算由后端单独验收。

设置页接入共享运行配置：CPU/CUDA/自动、显卡卸载层数、上下文长度；Kokoro/系统音色/自定义TTS服务及其参考音频路径和语言；ASR设备/精度。仅保存设置并不证明CUDA设备兼容、音色授权或模型安装完成。自定义远程服务会接收朗读文字，界面已说明。参考音频路径是语音服务所在电脑的文件，未提供参考音频上传器。
