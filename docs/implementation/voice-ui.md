# 浏览器声音生命周期：首轮实现

日期：2026-11-12。实现位置：`app/static/app.js`。

## 已实现

- 新聊天、停止生成、停止声音和页面离开均先使本机声音失效；暂停播放、撤销 Blob URL，并中止尚未完成的 HTTP 取音频请求。
- 每次朗读使用独立序号。提供方忽略 AbortSignal、响应体晚到或旧 Audio 事件晚到时，旧声音不能重新播放，也不能清除新声音的状态与资源。
- 系统语音回调使用相同的序号检查。停止先使旧序号失效，再调用系统取消，避免取消事件污染下一段声音。
- SSE 元数据与完成事件记录 `generation_id`。自动朗读提交 `{text, generation_id, request_id}`；历史消息与约定朗读提交 `{message_id}`，由服务端解析原文。设置试音保留 `{text}`。
- 停止操作中的后端取消失败会显示错误，但本机已经停止，不会因此恢复旧声音。完成的生成也可通过声音停止按钮请求取消其关联 generation。
- 在生成或停止期间收到的主动消息仍可显示，但不会抢占朗读。
