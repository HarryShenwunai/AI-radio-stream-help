# 自助PNG角色交付记录

更新：2026-11-12，Europe/London。开发版本0.4.0-dev1。用户目标平台是Windows 10/11；当前实际实现与本机证据以PNG路径为范围，Windows CI和目标机器仍待验证。

## 本批行为

用户可创建任意名字的独立角色，导入自己的静态PNG并在应用内预览、配置和启用。说话、眨眼、说话时眨眼图片可选，单张图可用。外观按修订保存，使用旧修订即可回退，不要求开发者为某个角色修改配置或源码。

角色身份与外观分开。换同一身份的外观保留聊天、记忆和约定；新建身份使用独立数据库。归档保留关系，恢复可再使用；永久删除有当前身份切换、最后一个可用角色和物理清理回执保护。

模型提供方连接由所有角色共享，密钥留在本机。切换身份不会激活另一份旧API地址；凭证不一致、连接快照过期或写入失败时拒绝发送，避免把已有密钥发给错误服务。人格和关系数据仍按身份隔离。

停止、角色切换和外观更新共同使旧媒体失效。浏览器先停止当前声音，服务端拒绝迟到合成结果，状态图随实际播放/停止变化；这不是Live2D或音素级口型。

## 当前格式与限额

| 项目 | 当前实现 |
| --- | --- |
| 输入 | 静态PNG；idle必需，talk/blink/talk_blink可选 |
| 尺寸 | 同一组状态图尺寸一致；每边不超过4096像素 |
| 预算 | 每图4MiB、整组8MiB、所有状态合计800万像素 |
| 编码 | 验证PNG结构、CRC与实际解码；拒绝16bit和APNG |
| 规范化 | 转为RGBA并移除附加元数据，另做缩略图 |
| 数量 | 50个身份、每身份30个外观修订的初始工程限额 |
| 能力边界 | 没有Live2D/model3.json、VRM、PSD绑定或其他应用专用角色文件导入 |

推荐sRGB/8bit、透明背景。当前会去除ICC/gAMA等元数据而不做源色域转换，宽色域素材可能出现色差；不能称色彩管理已经完整支持。这些限额是当前实现预算，不是对所有画师的行业要求。

## 数据与升级

旧根数据库通过SQLite backup迁入第一个角色，支持读取已提交WAL，保留旧源文件。应用此后使用`profiles/<UUID>/companion.db`，不会合并旧版继续产生的新记录；升级前须停止旧进程并备份。

每个身份的PNG修订留在该身份目录。模型权重与音色目录可通过环境变量复用，不因新建角色复制一份LLM。共享提供方连接与密钥位于数据根目录。

界面导出不是完整图片资产备份；完整迁移需要在停止应用后复制整个数据目录。归档、删除、恢复、遗忘账本与新旧角色归属均有单独测试。清理失败通过cleanup_pending说明并保留重试记录，不承诺存储介质安全擦除。

| [Linux桌面整包](../../desktop/test-results/bundled-app-smoke.json) | 14项通过 | 实际应用页与内嵌后端、PNG、透明和隐藏/恢复；不含Windows或模型质量 |

Chrome布局检查覆盖1440/390/360 CSS px；真实Audio播放时间推进、切换身份停声及单播放拥有者已测。测试启动允许autoplay，默认浏览器限制与目标机声卡尚未完成验收。

Linux编译后端单次观测：首段文字9.206秒、完整15.993秒、TTS3.645秒生成4.821秒音频、协作取消0.099秒，峰值RSS5568992KiB约5.31GiB。这是单次云端Linux观察，不能作为Windows p95、最低配置、性能提升或自然度证明。

真实模型成功生成和合成不等于输出质量达标。**模型自然度与长期相处质量仍未人工接受**，输出可能不自然或不准确。当前PNG测试也使用合成几何图形，不代表已完成最终二次元角色美术。

## 尚未完成

Live2D与VRM、全28项多格式验收、Zerolan实际模型互通、B站/弹幕姬/OBS、微信、AR、MC与云同步/角色市场尚未完成。SDK、模型与素材的发布许可仍需各自确认。

没有目标用户硬件的长期资源测试、穷尽断电/故障注入、所有窗口管理器或独占全屏游戏覆盖。HTTP请求关闭可能留下未启用资产修订，用户可删除；它不会替换当前外观，仍不能称所有socket中止都已证明底层处理取消。
