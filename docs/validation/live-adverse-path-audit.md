## 验收协议及反例

判据在相应修改前确定：未提交草稿完全保留；旧响应不覆盖新响应；待批准请求单次；失联/过期任务不可再播；故障可见；字幕不静默裁切；待审答案在突发问题之前；停止后本页无持续播放。原有30秒TTL、250ms轮询、1250ms断联截止未为测试放宽。浏览器断网停止预算1500ms来自现有截止与调度余量，不是Windows性能承诺。

保留 state-before.log、ui-before.log、ui-negative-control.log、browser-before/report.json、review-priority-before/report.json。最后一项专门证明优先顺序旧版失败。旧源码CONNECTOR_UI_SOURCE负对照使用新测试，不覆盖旧日志。开发样例已用于修复，不能再称为未见验收集。

键盘进入设置、390/1280横向布局在旧版即通过；未计作修复成果。覆盖范围未包含屏幕阅读器、所有缩放比例、长时间压力、真实音频回流及目标设备性能。
