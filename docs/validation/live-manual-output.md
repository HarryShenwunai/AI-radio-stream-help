## 固定约束

未经逐条批准无音频队列；变更教材、切房、停止或私人接管后撤销旧输出。
同一来源/房间/事件在同一连接只生成一次；失败不自动重试。
每个音频仅一个消费者；终态不能通过迟到回执改为完成。
公开生成输入仅包含公开表达方式、允许公开的教材和当前问题，不加入私聊记录。
本机播放结束始终 delivered=false；观众收到必须另有双端证据。

音频最多20MB、同时只准备或持有一条；100任务/连接，500条内存审计。
问题仍使用原来的30秒期限，包含生成、审核与播放；过期会停止，不在断线后补播。
这可能不足以完成慢速本地模型作答，应在真实设备测量后决定是否需人工重新选题，不能偷偷放宽期限。

## 使用与下一阶段

微信与直播连接 → 哔哩哔哩直播预览 → 设置允许公开的教材 → 打开输出页并启用音频。
连接已授权Open Live房间，选问题生成，核对回答后逐条批准。立即停止会取消任务并撤销输出页令牌。
仅支持现有本地/外部WAV合成，系统浏览器朗读不作为此输出通道的替代。

真实B站阶段所需：直播间号、已授权且在目标机本地配置的Open Live凭据、实际模型和音色、OBS版本、目标Windows环境、观众端采样协作。
凭据不写进仓库/聊天/录像。先验证接收协议与一条真实提问，再批准单条字幕与音频输出。
未授权自动回应、自动公开输出或平台文字发送。输出页是OBS候选输入，不是已完成OBS验收。

外部评审人员使用未见题，比较材料依据、等待/打断、主播接管和观众独立作答。
