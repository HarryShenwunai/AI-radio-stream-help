# 自助角色导入：分级基准与验收设计

日期：2026-11-12，Europe/London。范围是研究与测试规格；未改应用UI、未实现导入器、未下载或运行第三方模型。所有新增导入测试为 **NOT_RUN**，夹具尚未制作。本文件由独立审查Agent编写，供总计划整合。

## 目标与已知现状

目标是用户自己导入符合已声明格式的角色包，在应用内完成预览、能力映射、启用、切换和删除；无需开发者改源码或发布一个专用版本。示例角色只作测试，不成为角色白名单。“可自助”不等于支持任意文件、自动把单张原画制成完整Live2D，或自动获得素材使用权。

现有代码可复用generation取消、晚到声音拒绝、独立公开事件入口、HTTP/SQLite及单模型运行。实际读到的`app/server.py`目前只有一套settings/messages/memories/tasks，没有character_profile_id；`Scope`只包含channel与session_id。它尚不具备多角色资产、身份、关系记录隔离。旧115项Python回归不代表新导入路径通过。

切换需先定义两种操作：

- **同一角色换外观**：更新asset_revision_id，保留该角色的已授权身份与会话；须停止旧动画、旧声音并重绑映射。
- **新增或切换独立角色**：不同character_profile_id；关系记忆、提示配置、会话、主动约定默认隔离。共享用户事实若要存在，应有明确选择，不能隐式复制。

角色身份、资产修订、会话和generation联合确定一轮输出的归属；素材包里的名字、路径或“主人”字段不能成为身份凭证。恢复备份和遗忘账本也必须按相同边界验证。

## 基准能力分级

以下是本项目的候选测试分级，不是Live2D行业标准，也不是已批准的首版支持清单。发布时逐项声明支持格式、版本和能力，未支持项可明确拒绝。

| 分级 | 候选输入/能力 | 夹具性质 | 重点验收 |
| --- | --- | --- | --- |
| C0 静态角色 | 透明PNG和基础元数据 | 自造无人物图形，含透明边缘与不同画幅 | 选择、预览、缩放/锚点、启用、删除；不伪装有绑定动作 |
| C1 状态图片 | 待机/眨眼/说话等图片及显式状态映射 | 自造图形状态集，含缺可选状态的版本 | 默认回退、说话驱动、停止归位；路径与键名不写死 |
| C2 Live2D基础 | 选定版本的完整运行包和基础参数 | 许可已核对的官方样例，固定版本；目前未获取 | 实际渲染、依赖解析、基础眼口/待机与停止 |
| C3 Live2D非标准绑定 | 自定义参数ID、范围/默认值、可选表情/动作 | 独立创作者授权包；与C2不共享硬编码名称 | 在应用内重映射、缺能力降级、与通用状态隔离 |
| C4 其他渲染器 | 例如未来另立版本的VRM适配 | 另做独立清单，当前不纳入默认支持承诺 | 未安装适配器时可理解地拒绝，不错误当Live2D加载 |

至少要用两个独立结构的包验证每条拟发布的导入路径；其中一个应在实现完成后作为保留样本加入。这里的“两个”是防止针对单一样例写死的候选最低抽样，不是足以证明通用性的统计保证。正式样本数量按支持格式和版本扩大。

测试可使用官方允许相应用途的样例或明确授权资产；下载、修改、运行、公开分发是不同权限。测试索引记录来源、版本、SHA256、权利范围与允许动作，尚未核对的素材不得当可分发fixture。坏包由自造或获准样本做本地变异，不从不明来源获取。

## 导入路径与边界

建议生命周期：选择本机文件 → 隔离暂存 → 包结构/资源预算检查 → 运行时预览 → 用户映射和确认 → 原子启用 → 可回滚版本。失败或取消只清临时目录，不能改写当前可用角色。

文件结构校验与运行语义校验分别记录。JSON字段齐全、扩展名正确、哈希一致都不能证明纹理可解码、模型版本兼容、动作可执行、口型正确或许可真实有效。

包引用只解析到本包的受控资源根目录。检查规范化后路径、符号链接、硬链接、绝对路径、Windows驱动/UNC、重复条目、大小写/Unicode规范化冲突及依赖循环。声明中不得携带可执行脚本、插件、任意网络地址、密钥或要求提升系统权限的动作。模型元数据是数据，不授予工具权限。

压缩包字节数只是一个维度。还需分别限制实际解压字节、条目数、嵌套/依赖深度、压缩比/处理时间、解码图片像素、纹理数量与尺寸、JSON深度、网格/物理复杂度、CPU/GPU内存和预览时间。资源上限由目标机与渲染器样例确定；不能仅靠ZIP目录宣称的长度，也不能只在全部解压后才检查。

基础RGBA8像素缓冲可按Σ(width×height×4)估算，但这只是该缓冲的理论量，不是总内存。纹理上传、mipmap、解码副本、预览与当前角色并存、渲染器和进程开销都需实际观测。尽量流式读取/限额写入；暂存和加载要能停止。

## 拟执行的测试矩阵

机器可读详情见[character-import-test-specs.json](../../review/character-import-test-specs.json)。每项actual_result为null，不能从规格数量得出通过率。

| 组 | 正常/边界/失败用例 | 可观察结果 |
| --- | --- | --- |
| 泛化与自助 | 新包名称、目录布局、Unicode路径、两套独立模型、自定义参数 | 受支持输入能在应用内完成，不改源码、不靠样例名判断 |
| 结构与语义 | 坏JSON、伪扩展、缺纹理、错误moc/版本、不可读动作、异常参数范围 | 准确指出阻塞或可降级项；旧角色继续可用 |
| 资源边界 | 大像素小PNG、高压缩ZIP、超多文件、深层依赖、复杂物理与纹理 | 在既定预算前受控终止；可恢复，仍能导入正常包 |
| 权限与路径 | 路径穿越、符号链接、条目冲突、外链、脚本、自称owner | 不访问包外文件、不发起外链请求、不执行代码 |
| 事务与恢复 | 导入取消、预览失败、更新中断、磁盘不足、重复导入、应用重启 | 无半安装状态；当前版本可用；暂存可清理；升级可回滚 |
| 角色与媒体 | 换皮、换独立身份、旧音频晚到、双窗口、切换中正在说话 | 不串关系记录；单播放拥有者；旧资产动作不复活 |
| 删除与导出 | 删除当前/非当前角色、保留或删除关系数据、恢复旧备份 | 操作范围明确；撤销激活与旧generation；遗忘事实不被恢复 |
| 桌面表现 | 不同小窗尺寸、DPI、透明边缘、穿透区、待机/隐藏/展开 | 用户能辨识角色并操作；不因不同素材抢焦点或遮住停止 |

缺口型参数时可以静态显示并明确能力，不将随机参数当嘴；缺表情或动作时回到中性/已有待机，不能使基础聊天失效。参数ID和范围从实际包发现或用户映射，不靠固定角色名猜测。

## 可计算的成功标准

| 指标 | 计算与数据来源 | 初始目标依据/评估时点 |
| --- | --- | --- |
| 自助完成率 | 无开发者介入完成导入并启用的有效包数÷该格式有效包测试数；观察日志/任务录像 | 用户目标要求受支持流程零源码改动；完成率阈值待首轮用户基线；发布前评估 |
| 支持范围符合率 | 声明支持的格式/版本/能力组合中通过的组合数÷已测声明组合数；兼容矩阵 | 发布声明必须与实际结果一致；未测或失败组合不列为通过 |
| 错误处理正确率 | 获得预期拒绝/降级并保持原角色的失败夹具数÷已执行失败夹具数 | 拟定工程条件：安全/事务关键用例全部满足；任何失败留阻断记录 |
| 串角色信息 | B角色模型请求、记录、日志、字幕中出现A专属canary次数；用合成事实验证 | 默认隔离场景0；用户明确共享的字段另设允许表；身份迁移后回归 |
| 晚到媒体 | 切换/删除后旧asset_revision或generation的播放/动作生效次数 | 拟定工程目标0；覆盖TTS、下载、渲染回调、展开窗口 |
| 导入与切换时延 | 选择→首个有效预览，确认→可交互，取消→停止写入分别计时；p50/p95 | 固定样本和目标设备后测；数值门槛待定，不冒充现有首段模型时延 |
| 资源增量 | 后端静态基线→宿主→静态角色→动画→预览并存→切换后的完整进程树差值 | RSS/CPU/GPU/显存/帧时间和临时磁盘一并测；预算待设备确认 |
| 资源回收 | 反复切换/删除后残留播放器、纹理、定时器、临时目录及内存趋势 | 无未释放对象增长和旧输出；循环次数/稳定窗口先做基线确定 |
| 小尺寸可用性 | 同一角色多画幅和DPI的识别、误触、输入/停止任务完成记录 | 先用户任务基线，不假设统一头身比或固定像素适合全部桌面 |

只有实际运行测试后才计算通过率。失败样本与无法执行项必须保留，不能从分母剔除以美化结果。生成/合成成功不等于用户看见/听见。

## 工作包与依赖

| 包 | 负责人 | 前置 | 交付物 | 验收/估算条件 |

| CI-B4 生命周期与桌面 | 媒体/桌面开发 + QA | CI-B2、CI-B3 | 单播放拥有者、身份切换、隐藏/删除/恢复 | 复用generation但新增资产身份；目标机验证 |
| CI-B5 用户与资源验收 | 用户 + QA + 独立审查 | CI-B2–CI-B4 | 自助任务、资源对照、失败与兼容矩阵 | 达到已约定门槛，未解决项不隐去；发布前执行 |

## 排序风险与处置

| 优先 | 风险/预警 | 预防和失败处理 | 责任 |
| --- | --- | --- | --- |
| 1 | 解压/解码/渲染越界或资源耗尽；小包异常展开 | 多层预算、隔离预览、终止与清暂存；保留旧激活版本 | 导入器/渲染开发 |
| 2 | 角色身份/关系数据串用；新角色出现旧canary | 独立ID与明确共享语义；停用新切换路径并恢复旧记录快照 | 后端开发/QA |
| 3 | 更新中断破坏唯一可用包；半成品被激活 | 不覆盖原目录、校验后原子发布、备份回滚 | 后端/桌面开发 |
| 4 | 格式存在但实际参数/版本不兼容；只对官方样例有效 | 多来源保留样本、实际加载与映射、明确不支持项 | 渲染开发/绑定师 |
| 5 | 界面切换重复发声或旧口型复活 | 一个媒体拥有者、资源修订与generation同时失效 | 媒体/前端开发 |
| 6 | 权利范围不清、用户误以为包能公开分享 | 元数据与使用声明分开；云分享另行设计，不自动外发资产 | 产品负责人/权利人，必要时专业确认 |

## 证据、假设与未解决项

已核实本地事实：现有单套数据库结构、generation与晚到检查，以及历史测试边界。路径与调用点见[server.py](../../app/server.py)、[lifecycle.py](../../src/companion_runtime/lifecycle.py)和[既有独立审查](../../review/phase1-independent-review.json)，读取于2026-11-12。

一手安全资料：[OWASP File Upload](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html)说明需组合验证类型、内容、名称、权限和资源限制；[Python 3.12 zipfile](https://docs.python.org/3.12/library/zipfile.html)说明压缩包条目、提取与异常行为。它们不替本项目设定具体资源阈值，也不证明拟导入器已安全。本轮访问日期2026-11-12；源码未实现。

本文件关于分级、事务、身份隔离、回退与测试数量的内容是工程建议。外部渲染器真实兼容、许可、目标OS/GPU、上传是否要云端共享、首版格式清单、参数范围与资源门槛仍未知。以隔离样例、许可核对和用户任务观察解决，不用完整格式列表掩盖缺证据。

实际pitfall供主Agent交接：现有generation关联不含角色/资产版本；切换视觉资产可能误被实现成换独立人格，反之亦然。ZIP小不代表纹理小，Schema合法不代表加载成功；来源/权利字段也不等于授权已经核验。这里均是静态审查发现或设计风险，不能称为已复现的运行漏洞。
