## 本轮目标与不变量

只让一条本地现场文字经准备、主播审核、单次批准，在同一节目画面驱动原角色、字幕和实际音频，可停止并在两端看见终态。默认现场互动，不强迫教材；严格答疑另需明确公开材料。

仅Windows10/11 PC为产品目标（RTX4060、32GB）；本轮开发验证在Linux CPU/Chrome。保留角色身份、发型、光照、卫衣与固定持杯。真实B站/OBS暂停；不做手机、无依据的小组件扩张、自动公开、平台发字、合并、部署或发布。用户最新允许为正面和自然度重做必要素材；静态候选不等于已绑定或默认已替换。

不以PR/功能/测试数量衡量完成。视觉专业感仍被用户退回；不能靠状态绿测宣称审美改善、青春声线达标或学习受益。

## 实施方法、文件域与回退

B独占server输出路由、live_output.py、live-stage、ProgramScene和可选renderer transport及相关测试；C独占connectors-ui与控制台测试。接口请求经B单一负责人，不交叉并写。P9管理、审核、运行最终测试和证据交付。内部AI审查仅为开发检查，不能当独立人员验收。

复用现有状态机、Core、音频、可见页刷新；无新增产品依赖、后台线程或轮询。节目v1原固定右人物、左字幕；本轮仅同身份已应用布置经白名单冻结进入节目，保留透明底。草稿与任意配置不得自动公开，活动输出须停止后重新打开。

每个根因独立提交：节目绑定/媒体顺序；完成回执丢失；主播局部更新；测试隔离；ORT初始化前隐私修复；拒绝原因；实际WAV预算。可逐项git revert，不能用整目录覆盖用户材料。源码补丁不含模型/SDK/权重/数据库/凭据。

## 固定判据与验证顺序

1. 未批准不得输出；私人或未知字段不得进入节目；资源只限批准快照并核实际hash。
2. 重复、取消、过期、切身份/外观/话题后旧任务不复活；audio.play/AudioContext失败不报真实播放。
3. 同job字幕、原角色口型与实际音轨对应；字幕不遮手杯，原包hash不变。
4. 完成回执丢失保留未确认；状态刷新不破坏草稿/凭据/焦点；BC仅提示重读权威状态。
5. 30秒不变；实际WAV在ready/claim/audio边界已必然来不及时拒绝，不靠缩题、改语速/提示词或延长期限掩盖。它不是未知设备延迟下绝不截断的保证。
6. 先冻结源码跑完整质量入口（lint/限定strict typing/架构与坏夹具/协议/桌面/UI），再顺序真实模型/TTS，不相互竞争。实际长题保留，已有问候另作合成开发正向。
7. 浏览器/模型测试仅loopback新namespace，ORT初始化前禁用遥测。原生syscall跟踪被环境拒绝，不绕过、不宣称全系统零调用。

失败必须留下旧红/新绿/坏版本仍红；不能只选好看的帧。报告、原始输入、实际WAV/WebAudio、未剪辑双端录像、Trace审查副本与源码复跑命令共同交付。Trace审查副本省略资源响应体，不冒充完整原始Trace。
