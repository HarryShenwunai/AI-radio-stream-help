# 小岚 v0.2 本轮交付记录 · 2026-11-12

目标：提高当前相处体验，减少旧记忆对闲聊的干扰，并完善可控的聊天、语音与约定操作。B站与弹幕姬是新增研究计划，本包尚无这两种接入；微信仍未接入。

## 已完成改动

- 当前对话优先；只在询问过往、偏好或相关选择时查长期记忆。最多3条450字，无命中不注入。一键「只聊当下」保留当前对话，关闭长期记忆读取。
- 随便聊、听我说、轻松一点；独立的角色偏好配置。不是情绪自动识别，也不需要靠记忆库建立角色。
- 真实SSE增量，停止生成，不保存半截回复；最近一条可继续/换个回答。失败重试保留原完整回答，不重复添加用户消息；发送前网络失败保留草稿和请求标识。
- 约定可以延后5分钟、由用户标记完成或取消。移动端也有语音开关；清理被中断的音频与Blob URL。
- 默认本地模型升级为Qwen3-4B-Instruct-2507社区GGUF量化；更强不等于没有幻觉。旧目录没有4B而有原1.5B时可回退，界面显示轻量。
- 有限表达检查：针对部分未请求追问、编造经历/环境和说教表述，最多一次生成式编辑改写，仍违规就报错不保存。正常回复一次推理；命中规则最多两次。草稿可能在结束前修正。

## 实际验证与限制

- 36项后端行为测试通过；真实HTTP配合本机模拟模型服务的5项协议测试通过。
- Chromium模拟服务测试通过模式/记忆偏好持久化、流式停止、重试去重、网络失败草稿恢复、XSS文本显示、约定延期/完成、来源与会话校验及1440/390/360布局。
- 真实Qwen3生成与事实召回、Kokoro中文WAV、浏览器HTMLAudio播放时间推进、真实应用内提醒通过。无JS错误。音频播放验证不是用户听感评价。
- 编译后的Linux程序实测：长期记忆关闭仍有真实增量回复；正确回答已保存饮品；真实生成中停止且不保存半句；本地中文语音有效。native-check.json为最终证据。
- 12个有限质量场景完成，4个触发过一次改写。该轮与编译存在CPU竞争，耗时不作空载基线。完成不等于人工质量全部通过：仍出现规则未覆盖的环境描写、表达生硬、媒体细节可能不准确等问题。不能声称消除了幻觉或自然相处已验收。
- 新原生测试最初错误地要求每个正确答案必须带“你”，把“桂花乌龙茶。🌿”判为失败。已保留失败记录，改为检查事实并拒绝第一人称冒认，没有强行改模型正确短答。

## 资源开销

云端Linux x86_64，5个可见逻辑CPU，cgroup配额4核、内存上限16GiB。推理最多4线程。

独立原生一次观测：无长期记忆首段9.229秒、完整回复11.205秒，事实回答3.628秒，生成中停止0.086秒，语音合成3.419秒。进程VmHWM/RSS5569316KiB，约5.31GiB。不是p95、压力测试、七日稳定性或最低硬件承诺。

相比旧1.5B，4B下载和内存代价显著增加。三个模型合计2851000503bytes，约2.85GB；完整包还含运行库。首次安装需预留数GB下载与解压空间。建议有足够空闲内存，16GB级设备更适合同时开浏览器等应用，具体设备实测。

按需改写最多增加一次推理，可能明显变慢。API方案也会增加相应token费用。前端轮询从2.5秒调整为5秒，隐藏标签页暂停轮询，减少空闲请求；没有捏造CPU改善百分比。
