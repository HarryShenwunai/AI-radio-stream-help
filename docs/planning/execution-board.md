- [Python回归](../../review/phase1-tests.json)：隔离数据库、协议与本机HTTP；模型/合成服务使用替身。
- [浏览器验证](../../review/phase1-browser.json)：实际Chrome和HTMLAudio，音频为24kHz测试音；允许自动播放的测试参数不代表默认浏览器策略。
- [真实本机冒烟](../../review/phase1-real-smoke.json)：实际Qwen3 4B与Kokoro、合成输入；不是人工自然度验收或p95。
- [离线队列回放](../../review/phase1-live-replay.json)：200条/秒×60合成秒，非真实持续60秒负载。
- [独立审查](../../review/phase1-independent-review.json)：已复现的问题、修正与剩余限制。

真实模型单次首段10.790秒、完整17.248秒；TTS 3.124秒生成2.602秒声音；协作式生成停止0.091秒；进程最大RSS 5525876KiB，约5.27GiB。这些值来自当前Linux，不能与旧观测直接推导提速/回退结论。首声端到端、目标机p95与额外模块RSS仍未验收。

离线队列峰值200；接纳1604/12000，取出60/12000，即0.5%。1344条在队列内过期、10396条因队列满丢弃，尾队列200条。取出是消费夹具行为，不是模型回复/实际播出。后续必须验证选题质量与覆盖率，不能只报告不崩溃。
