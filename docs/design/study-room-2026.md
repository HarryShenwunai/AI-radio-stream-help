# 学习直播间：从聊天入口到目标—专注—复盘

## 参考与取舍（2026-11-13 检索）

- Thetawave Focus https://thetawave.ai/feature/focus ：进入场景前选择目标与学习阶段，计时连接后续复习。采用“目标先于开始”和按需复盘入口，不复制素材、人数或其 AI 功能声明。
- StudyClock https://studyrooms.studyclock.com/ ：专注区间减少聊天打扰、休息再交流。这里保留用户主动提问，专注时只抑制自动朗读和自动提醒弹出。
- LifeAt https://lifeat.io/category/study-with-me ：场景与任务工具并存。保留原人物和已存在的背景，把任务台与角色画面分区。

这些是检索时可见的产品设计，不声称它们均在 2026 年首次发布，也不把宣传页功能当成本项目已实现。

## 实现

现有应用增加独立工作台，保留原对话、角色、平台管理、语音与隐私入口。学习状态机为 idle → running ⇄ paused → review → break → idle。15/25/50 分钟，手动结束，三类可勾选模板；AI 拆解/复盘只准备草稿，由用户编辑和发送。未连接模型时进入已有连接流程。无假在线人数、自动启动直播或虚构 AI 结果。

计时采用单调时钟差值，不依赖 interval 次数。重复时间/倒退不重复计时，暂停不计时，保存不重复累计；恢复到暂停，不追补关闭页面的时间。休息刷新回到待开始，不重复记入上轮。记录按角色隔离在本标签页 sessionStorage，可清空；存储失败可见提示，不隐瞒持久化失败。

桌面将角色与工作台隔开，窄屏按垂直顺序呈现；沉浸模式有始终可见的返回入口。保留日夜切换和桌面缩小/输出模式。学习期间不强行移动手与杯。

## “零公差”的具体边界

严格零容忍项：角色/控件交叠、页面横向溢出、未点击发送就提交 AI 请求、暂停期间累计学习时间、角色切换泄露目标、重复保存重复计数、专注状态触发自动朗读。分别由实际浏览器断言、单元测试和有界状态探索检查。

视觉不是可证明的“绝对 0 公差”：像素重采样、显示色彩和手绘判断仍存在差异。原始图与用户审美是最终基准；不能把单张生成候选或测试全绿称为原画完全一致。头发、脸、手杯原始素材保持独立，不用全脸生成替换来掩盖局部问题。

## 验证

`node --test tests/test_study_session.mjs` 覆盖状态机并有界探索 8 层、11 种事件、3 种时钟值（不是无界形式化证明）。

`tests/browser_audit.py --study-room` 在真实 HTTP 应用、已授权 Core 与实际模型中检查交互和布局，记录截图视频；测试 AI 和提醒用于隔离检查，不代表真实平台联动。运行时和角色包由操作者提供，脚本不下载或接受第三方许可。
